07 / DATA INTEGRITY

Relationships
we can trust

Concept → connection → concept

Valid endpoints, defined types, no self-links, and a unique ordered pair. Normalized input and service-side validation.

Atomic changes

Deletion removes incoming and outgoing edges in one transaction. Restore validates every record before writing into an empty atlas.

User-facing errors support recovery; unexpected exceptions are logged on the server.

09 / BFS & COMPLEXITY

A shortest chain
between ideas

Queue → neighbors → visited vertices → predecessors → reconstructed path

O(V + E) time and space

BFS explores an unweighted graph by layers. Visited vertices prevent cycles; discovery traverses either direction.

Practical resource limits

No-tracking reads, cached filters, bulk edge deletion, and at most 60 map nodes. The library and text result remain available.
